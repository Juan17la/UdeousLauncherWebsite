FAQ

Questions you might have

Click a question to open it.

What's an instance?

An instance is a separate copy of the game: one Minecraft version, one loader (or Vanilla) and its own folder with worlds, mods, resource packs, shaders, screenshots and settings. Your 1.21 survival world and your 1.20.1 modpack never touch each other.

Game files like libraries, assets and Java are shared, so a second instance of the same version downloads almost nothing. Each instance can also have its own memory, Java path and JVM arguments.

How do addons work?

The Addons page searches Modrinth for mods, resource packs, shaders, data packs and modpacks.

  • Add shows only the instances the addon fits (right version and loader). Pick one and it installs, required dependencies included.
  • From an instance's own Mods tab, Add from Modrinth installs straight into that instance.
  • A modpack can become a brand new instance in one click.
  • Files you add by hand (drop a .jar or pack) work too.
How do I run a server, and what are the options?

Go to Servers, then create one: Vanilla, With mods (Fabric, Forge or NeoForge) or From a modpack. Press Start and the launcher downloads and sets up everything.

  • Who can join: Udeos players (default, skins work), Anyone, or Microsoft accounts.
  • Internet: Relay mode (default) works without touching your router. Router mode opens the port with UPnP. Friends on the same Wi-Fi use your LAN address.
  • Tabs: Console, Players (whitelist, ops, bans), Backups, Mods, Datapacks and Settings (server.properties, memory).

Creating a server means accepting Mojang's EULA. Quilt servers aren't supported yet; most Quilt mods run on a Fabric server.

How do skins work?

On the Skins page, drop a .png you downloaded or click New skin to paint one on a 3D model. Pick Classic (Steve, 4px arms) or Slim (Alex, 3px arms); the launcher guesses the right one on import.

Click a skin in your library to wear it. It is used by every instance from the next Play, and it shows in singleplayer and on Udeos servers. Each nickname has its own skin library.

Can I personalize the launcher?
  • Theme: light or dark.
  • Language: English or Spanish.
  • Nicknames: keep several. Each one remembers its own theme, language and skins.
  • Per instance: name, icon, memory, Java path and extra JVM arguments.
Where are my instance folders?

Everything lives in one folder. Each instance is in instances/<id>/.minecraft inside it:

Windows%AppData%\UdeosLauncher\instances
macOS~/Library/Application Support/UdeosLauncher/instances
Linux~/.config/UdeosLauncher/instances

The easiest way is the Open folder button on an instance's page. Set the UDEOS_HOME environment variable to keep everything somewhere else.
